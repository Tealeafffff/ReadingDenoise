# 阅读降噪ReadingDenoise

浏览器插件，完全离线的网页阅读降噪工具。通过本地算法识别低信息量词汇并虚化显示，辅助阅读。

## 功能

- 本地识别中文低信息量词汇并差异化虚化
- 不删除、不遮挡原文，鼠标悬停可恢复清晰
- 支持虚化强度、运行开关和自定义词条
- 支持网站名单及“仅启用 / 仅禁用”模式
- 适配普通网页、动态页面和 Readest PDF
- 完全离线分析，不上传网页内容
- 针对性适配了PDF浏览网站Readest

## 安装

（正在上传Edge插件商城）
1. 下载 Release 中的 `ReadingDenoise_v1.0.1.zip`。
2. 解压到一个固定文件夹。
3. 打开 Microsoft Edge，进入 `edge://extensions`。
4. 开启左下角的“开发人员模式”。
5. 点击“加载解压缩的扩展”。
6. 选择解压后的文件夹。

## 使用

1. 打开需要阅读的网页。
2. 点击扩展图标，开启“阅读降噪”。
3. 按需要调整虚化强度。
4. 鼠标悬停在被弱化的文字上可恢复清晰显示。
5. 可在高级设置中管理网站名单和自定义词条。

## 隐私

ReadingDenoise的网页分析在本地完成，不向服务器上传网页内容，也不依赖在线AI服务。

## 已知限制

目前算法主要针对中文阅读场景进行了适配，英文和混合文本仍处于基础支持阶段。

## 技术

- JavaScript / Manifest V3
- LAC-ONNX 中文分词与词性分析
- ONNX Runtime Web
- jieba-wasm
- 本地词典、TF-IDF 与结构规则评分
